# План обеспечения разблокировки первого апгрейда

## Текущая реализация
В файле `Assets/Scripts/Shop/Shop.cs` уже есть логика для разблокировки первого апгрейда в нескольких местах:
1. В методе `UpgradesLockState` (строки 52-55) - первый апгрейд разблокируется при инициализации
2. В методе `FirstLoad` - вызывается `UpgradesLockState` для обоих списков апгрейдов
3. В методе `Load` (строки 82-90) - явная проверка и разблокировка первого апгрейда
4. В методе `ApplyUpgradeData` (строки 117-120) - разблокировка первого апгрейда при сбросе данных

## Проблема
Несмотря на наличие логики, для максимальной надежности нужно убедиться, что первый апгрейд всегда разблокирован.

## Решение
Добавить дополнительную проверку в метод `UpgradesLockState`, чтобы гарантировать разблокировку первого апгрейда независимо от состояния.

## Изменения
В методе `UpgradesLockState` добавить дополнительную проверку, которая будет всегда разблокировать первый апгрейд, независимо от того, как он был ранее установлен.

## Проверка
После внесения изменений необходимо убедиться, что:
1. Первый апгрейд всегда разблокирован при загрузке
2. Существующая логика не сломана
3. Все функции сохранения/загрузки работают корректно
