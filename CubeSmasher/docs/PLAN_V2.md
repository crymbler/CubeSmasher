## Шаг 1. Вы, сейчас — 10 минут

Цель: убедиться, что заготовки в новом тёмном стиле выглядят правильно.

1. В Unity: `Tools → CubeSmasher → Reset UI Assets (delete and rebuild)`.
   Пересоберёт кнопки, панель, полосу прогресса, монету и карточку в новой палитре.
2. `Tools → CubeSmasher → Verify UI Prefabs`.
   Проверит, что всё собралось. В Console не должно быть красных строк.
3. Выделить `Canvas` в сцене `CubeScene`, найти `Canvas Scaler`:
   - `UI Scale Mode` → `Scale With Screen Size`
   - `Reference Resolution` → `1080 × 1920`
   - `Match` → `0.5`
4. **Меню вручную не собирайте.** Напишите мне, что видно на экране.

Если что-то не так — скриншот, я поправлю палитру. Это одна правка в одном файле.

## Шаг 2. Я, следующий — сборка меню

Сделаю генератор готового экрана: `Tools → CubeSmasher → Build HUD Screen`.

Он соберёт один префаб со всем меню сразу:

- **Верх:** баланс с монетой, номер стадии, полоса прогресса, доход «+N/сек».
- **Низ:** четыре кнопки с иконками — гараж, магазин, скины, настройки.
- **Окно магазина** с карточками улучшений.
- **Окно гаража** с машиной и описанием.
- Правильные якоря и отступы, чтобы не разъезжалось на разных экранах.
- HUD скрывается, когда открыто окно гаража или магазина.

После этого вы: перетаскиваете префаб в сцену и смотрите. Ручной расстановки нет.

### Текст

| Роль | HEX | Где |
|---|---|---|
| Основной на тёмном | `#FFFFFF` | заголовки, значения, названия |
| Вторичный на тёмном | `#8FA8E8` | подписи, уровень |
| На неоне и светлом | `#1A2438` | подписи на зелёных и голубых кнопках |

**Правило:** на тёмном металле текст белый, на неоне и светлом металле — тёмный. Код выбирает цвет сам по яркости фона кнопки.

### Прочее

| Роль | HEX | Где |
|---|---|---|
| Монета | `#FFE040`, обводка `#C9A000` | софт-валюта |

### Форма

- Углы **квадратные**, без скруглений.
- Фаска: светлая полоса сверху 8 px, тёмная снизу 8 px.
- Контур 4 px.
- Отступ от края экрана 24 px.

## Шрифт

**Rubik** — https://fonts.google.com/specimen/Rubik (SIL OFL).

Годится потому, что в нём есть латиница, кириллица и турецкие буквы (ç ğ ı İ ö ş ü).
**Не брать** Baloo 2 и Fredoka: в них нет кириллицы.

Как собрать шрифт:

1. `Window → TextMeshPro → Font Asset Creator`.
2. Source Font File — файл Rubik.
3. Character Set → `Custom Characters`, вставить строку ниже.
4. Atlas 1024×1024, Render Mode `SDFAA`.
5. Generate, сохранить в `Assets/Art/Fonts/`.

Строка символов:

```
ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789 .,:;!?%+-/()[]{}=<>«»—–№
АБВГДЕЁЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯабвгдеёжзийклмнопрстуфхцчшщъыьэюя
çğıİöşüÇĞÖŞÜ
```
