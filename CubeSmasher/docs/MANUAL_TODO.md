- [ ] В консоли создать **лидерборд** с именем `stage` (точно, как в коде `EconomyInitializer.LeaderboardName`). Тип: максимум.
- [ ] Включить лидерборды в настройках плагина (`InfoYG` → Leaderboards → enable).
- [ ] Межстраничная реклама: в `InfoYG` → InterstitialAdv задать `interAdvInterval` = `300` (5 минут), `showFirstAdv` = `false`. Задержка 2 минуты после старта: см. ниже.
- [ ] Задержка 2 минуты после старта: в коде **не сделана**. Плагин сам вызывает `SetTimerInterAdv` при старте (`InterAdv_yg.cs`), поэтому свой вызов может конфликтовать с его таймером. Метод `YG2.SetTimerInterAdv(int)` публичный. Решить: либо оставить поведение плагина, либо добавить вызов после проверки. Пишите мне, сделаю.
- [ ] Rewarded: в консоли создать рекламный блок с ID `lifetime_reward` (совпадает с `_rewardId` в `LifetimeRewardAd`).
- [ ] Покупка «Убрать рекламу»: создать товар в консоли, записать его ID. **Кнопка и покупка в коде не сделаны** — ждёт ID товара, отдельная задача.

## Что проверить в коде, если что-то не работает

- Ошибки компиляции — пришлите текст из Console.
- Компенсация не видна — проверить, что `_rewardPanel` назначен у `LifetimeRewardAd`.
- Лидерборд не обновляется — проверить имя таблицы `stage` в консоли и что игрок авторизован.
- Локальный прогресс — ключ `smasher_local` в PlayerPrefs (можно очистить вручную для проверки).
